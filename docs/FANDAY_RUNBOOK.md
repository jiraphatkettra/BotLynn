# 🚨 FANDAY OPERATIONS & INCIDENT RUNBOOK (คู่มือเผชิญเหตุฉุกเฉิน)

> เอกสารสำหรับทีมผู้ดูแลระบบและแอดมิน เพื่อรับมือ แก้ไขปัญหาเฉพาะหน้า และกู้คืนระบบกิจกรรมแฟนเดย์ 753BC ให้ราบรื่น 100% ภายใน 5 นาที

---

## 1. กรณีบอทดับ / ออฟไลน์ระหว่างจัดกิจกรรม (Bot Crash / Restart)

### ผลกระทบ
- ปุ่มบน Discord อาจไม่ตอบสนองชั่วขณะ
- สมาชิกไม่สามารถกดสมัครหรือส่งคำตอบได้

### วิธีแก้ไข & การกู้คืน (Recovery Steps)
1. **บอทมีระบบ Auto-Recovery ในตัว**:
   - เมื่อบอทสตาร์ทกลับมา (`ClientReady`) บอทจะทำการ Reconcile ค้นหา Event ที่ยังไม่จบและอัปเดต Panel ใน Discord ทันที
   - State ทั้งหมด (ผู้สมัคร, ข้อมูลคำตอบ, การล็อกคู่, สถานะเกม) ถูกบันทึกลง Supabase PostgreSQL แบบ Real-time **ไม่มีข้อมูลสูญหาย**
2. **หากบอทยังไม่สามารถเปิดได้ทันที (ใช้เวลาเกิน 5 นาที)**:
   - เข้าหน้าเว็บ **Web Dashboard (`/fanday`)**
   - ไปที่แท็บ **"ความปลอดภัย & กู้คืนฉุกเฉิน (Ops)"**
   - ใช้ช่องทาง **Discord Webhook Fallback** พิมพ์ข้อความประกาศแจ้งสมาชิก เช่น:
     > *"📢 แจ้งเตือน: บอทกิจกรรมกำลังรีสตาร์ทระบบชั่วคราว ข้อมูลของผู้เล่นทุกคนถูกบันทึกไว้อย่างปลอดภัย และจะเปิดให้ดำเนินการต่อในอีกไม่กี่นาทีครับ"*
   - ปรับสถานะกิจกรรมเป็น `PAUSED` จาก Dropdown บน Dashboard เพื่อหยุดตัวนับเวลาทั้งหมดชั่วคราว

## 2. กรณี Gemini AI ไม่ตอบสนอง หรือโควตาหมด (AI Outage / Rate Limit)

### ผลกระทบ
- การประเมิน Personality Type อาจไม่ได้รับข้อความสรุปจาก AI

### วิธีแก้ไข & การทำงานของระบบ
- **ระบบมี Rule-Based Fallback 100% ในตัว (`aiTypeService.ts`)**:
  - หาก API Key ไม่ได้ตั้งค่า หรือการเรียก Gemini API ใช้เวลานานเกิน 8 วินาที ระบบจะสลับไปใช้ Heuristic Keyword Scoring โดยอัตโนมัติ
  - ผู้เล่นจะยังคงได้รับ 1 ใน 8 Archetypes ที่เหมาะสมตามคำตอบ และกระบวนการจับคู่จะไม่หยุดชะงัก
  - แอดมินสามารถตรวจสอบการตั้งค่า `GEMINI_API_KEY` ใน `.env` ได้ในภายหลัง

## 3. กรณีสมาชิกมีจำนวนเป็นเศษ (เพศไม่สมดุล หรือจำนวนคนคี่)

### แนวทางปฏิบัติ
1. ในหน้า Dashboard (`/fanday`) กดปุ่ม **"🔍 ทดลองจับคู่ (Dry-Run)"**
2. ระบบจะรายงานจำนวนคู่ที่จับได้ และรายชื่อผู้เล่นที่ยังไม่มีคู่ (`unpaired`)
3. แอดมินสามารถเลือกแนวทางได้ 2 รูปแบบ:
   - **แนวทาง A (เปิดรับเพิ่ม):** ขยายเวลาลงทะเบียน และประกาศหาผู้เล่นเพิ่มตามเพศที่ยังขาด
   - **แนวทาง B (Bye Priority):** ผู้เล่นที่เหลือจะได้รับสิทธิ์เป็นคิวสำรองลำดับที่ 1 สำหรับกิจกรรมแฟนเดย์รอบถัดไป

---

## 4. กรณีสมาชิกปิดรับข้อความส่วนตัว (DM Closed)

### ผลกระทบ
- บอทไม่สามารถส่งข้อความเปิดเผยคู่ หรือส่งจดหมายเข้า DM ได้

### ระบบสำรอง (Fallback Delivery)
- ระบบของ LynnBot ได้ออกแบบ **Multi-Channel Delivery**:
  - นอกจากส่งเข้า DM แล้ว บอทจะส่งข้อความแจ้งเตือนและข้อความจดหมายเข้าสู่ **ห้องกิจกรรมส่วนตัวของคู่ (Private Pair Room)** ด้วยเสมอ
  - สมาชิกสามารถกดปุ่ม **"🔎 บทบาทของฉัน"** ที่แผงหลักเพื่อเปิดดูข้อมูลคู่และข้อความได้ตลอดเวลา

---

## 5. กรณีพบผู้ใช้งานประพฤติตัวไม่เหมาะสมในห้องคู่

### ขั้นตอนดำเนินการ
1. สมาชิกสามารถกดปุ่ม **"🚩 รายงานปัญหา"** ได้โดยตรงจากห้องกิจกรรมส่วนตัว
2. ข้อความแจ้งเตือนจะถูกบันทึกลงสู่ `AuditLog` ในหมวด `FANDAY` ทันที
3. แอดมินสามารถเข้าตรวจสอบห้อง หรือใช้คำสั่ง `/warn <user> <reason>` เพื่อออกใบตักเตือน
4. หากจำเป็นต้องแยกคู่ แอดมินสามารถปรับสถานะคู่ในฐานข้อมูลเป็น `DISSOLVED` และย้ายผู้เสียหายเข้าสู่ระบบจับคู่ใหม่ได้ทันที
